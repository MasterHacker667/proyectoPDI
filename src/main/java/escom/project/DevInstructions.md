Dentro del Main tenemos clases que conforman, y encabezan el diseño aqui:
- MainWin es la clase central, esta se encarga de ser el centro del GUI.
- CustomHeader: es la cabecera, la que tiene los botones para cargar y señalar la imagen que estamos trabajando.
- CustomSidebar: esta es la clase que contiene la barra izquierda.
- CustomFooter: Esta clase contendra los botones para los histogramas y datos estadisticos.

El paquete de Backend contiene las acciones y metodos que estas deben llegar a cumplir y tambien una clase extra llamada Imagen que contiene la informacion de las imagenes que se suban.
